# Low-End Lock — 用户说明文档

## 1. 这个插件是干什么的

它解决 **Kick 和 Bass 在低频段「反相抵消」** 的问题。

低频里 kick 和 bass 常常叠在一起。两个波形同频时：

- **同相**（波形方向一致）→ 叠加，低频变厚。
- **反相**（波形方向相反）→ 互相抵消，低频变薄、变虚、变软。

传统做法是「侧链压缩」：kick 一响，把 bass 音量压下去躲开（ducking）。
Low-End Lock 走另一条路：**不压音量，而是把 bass 的低频段做相位对齐**，
让 kick 和 bass 从「反相抵消」变成「同相叠加」，把被吃掉的低频能量找回来。

用法：插件插在 **Bass 轨**，Kick 走 **侧链**，点 **Lock**，一键对齐。

## 2. 两个核心概念：极性与相位

- **极性（Polarity）**：波形的正负方向。「反极性」= 把波形上下颠倒（× -1）。
  对一个周期波形，反极性 = 所有频率统一转 180°。
- **相位（Phase）**：更广义，指每个频率的偏移角度，可能因频率而异。

插件用两个旋钮分别处理这两类问题：

- `Invert Polarity` 解决「**整段反相**」（180° 反相）。
- `Delay` 解决「**时间错位**」（部分频率错开）。

## 3. 各控件说明

### Gain（增益）

- 范围 -60 ~ +12 dB。
- 就是 **bass 的输出音量**，作用在相位对齐之后。
- 它**不影响对齐结果**，纯粹方便你在修正后补偿电平。

### Mix（混合 / 干湿比）

- 范围 0 ~ 100%。
- 0 = 完全原始（不做任何修正）；1 = 完全修正。
- 中间值 = 只修正一部分，效果更柔和。

### Invert Polarity（反极性）

- 把 **bass 的低频段**波形翻转 180°（× -1）。
- 用于「kick 和 bass 完全反相」的场景：翻转后由抵消变叠加。
- 注意：它**只翻低频段**，中高频的 bass 不动。

### Delay（延时）

- 范围 -20 ~ +20 ms。
- 把 **bass 的低频段**在时间上提前（负值）或推迟（正值），去对齐 kick 的波形。
- 用于「kick 和 bass 时间上没对齐」的场景。

### Low Band（低频段，即原来的 Low Cut）

- 范围 50 ~ 300 Hz。
- 决定「低频段」的**上边界**（低通截止频率）。
- **低于这个频率的部分**才参与相位修正；**高于它的部分完全不动**，
  以保留 bass 的中高频质感和清晰度。
- 值越大 → 修正范围越宽（更多低频被对齐）；值越小 → 越窄越精准。

### Manual / Auto（手动 / 自动）

- `Auto`：点 Lock 后自动分析，用建议的极性和延时。
- `Manual`：直接用你手动设的 `Invert Polarity` 和 `Delay`，即时生效，不需要 Lock。

### A/B（B fix / A orig）

- 一键旁路切换，听「修正后（B）」和「原始（A）」的差别，不重新分析。

### Lock

- 触发一次 2 秒低频采集 + 分析，完成后显示 `Cancelation Saved` 并自动应用修正。

## 4. 各预设说明

| 预设 | 参数 | 适用场景 |
|---|---|---|
| **默认** | mix=100%、自动、低频 150Hz | 通用起点 |
| **自动紧致** | mix=100%、自动、低频 120Hz | 只想修最底下一小段，不碰 120Hz 以上 |
| **极性翻转** | 手动 + 反极性、延时 0 | 经典「bass 和 kick 完全反相」，一键翻转 |
| **柔和混合** | mix=60%、自动、低频 180Hz | 想要柔和、只修一半、低频稍宽 |
| **宽低频** | mix=100%、自动、低频 250Hz | 相位问题延伸到更高频段，想整体对齐 |

## 5. 快速上手

1. 在 Bass 轨插入 LowEndLock。
2. 宿主顶部「侧链」菜单选 Kick 轨。
3. 播放 kick+bass。
4. 点 `Lock`，等 2 秒。
5. 看 `Cancelation Saved` 数字，用 `A/B` 听前后差别。
6. 自动结果不满意就切 `Manual`，手动调 `Invert Polarity` / `Delay` / `Mix` / `Low Band`。

## 6. 常见问题

### 为什么 `Cancelation Saved` 一直是 0 或很小？

说明你当前的 kick/bass **本来就没怎么反相抵消**，没什么可救。
数字是「随素材变」的：反相越严重，数字越大（能到 +6~+9 dB）。
想验证插件真的在工作，可以临时把 kick（或 bass）反相（Logic 的 Gain 插件里
勾 Phase Invert），再 Lock，数字会明显跳起来。

### 为什么有约 20ms 延迟？

要做 ±20ms 的「正/负」移相，需要一个中心偏移做基准，因此固有约 20ms 延迟。
这是相位对齐工具的结构性代价，适合混音，不适合实时监听。

### 为什么只处理低频，不动中高频？

相位抵消主要发生在低频。只动低频能避免破坏 bass 的中高频质感和立体声像，
也是让算法更轻、更稳。
