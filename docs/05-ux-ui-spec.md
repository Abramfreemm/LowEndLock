# Low-End Lock — UX/UI 规格

## 1. 设计原则

1. **一屏完成**：所有核心操作在一个视图内完成。
2. **结果优先**：用户最先看到的是 `Cancelation Saved`，而不是复杂参数。
3. **自动优先**：默认自动，手动为高级模式。
4. **可听可看**：所有关键变化都有 A/B 和视觉反馈。

## 2. 界面布局

### 2.1 单视图布局

```text
+--------------------------------------------------+
| Low-End Lock                            [BYPASS] |
|                                                    |
|  +--------------------------------------------+  |
|  |          LOW END PHASE MONITOR              |  |
|  |      Before: -4.2 dB   After: -0.3 dB      |  |
|  |      Cancelation Saved: +3.9 dB            |  |
|  +--------------------------------------------+  |
|                                                    |
|            [  LOCK / LEARN  ]                      |
|                                                    |
|  Polarity   [ Normal | Invert ]                    |
|  Delay      [====o===========]  -20ms .. +20ms    |
|  Low Cut    [====o===========]  20Hz .. 300Hz     |
|  Mix        [====o===========]  0% .. 100%        |
|                                                    |
|  [A] [B]  [Reset]             Status: Locked      |
+--------------------------------------------------+
```

### 2.2 核心控件

| 控件 | 类型 | 说明 |
|---|---|---|
| Bypass | 开关 | 旁通全部处理 |
| Lock | 主按钮 | 触发分析 |
| Polarity | 二态开关 | 手动覆盖极性 |
| Delay | 滑杆 | 手动时间补偿 |
| Low Cut | 滑杆 | 处理上限 |
| Mix | 滑杆 | Dry/Wet |
| A/B | 按钮 | 对比修复前后 |
| Reset | 按钮 | 恢复默认 |

## 3. 视觉设计

### 3.1 色彩

- 背景：深灰，接近 DAW 插件通用暗色。
- 主色：低频感的深蓝或橙红色，用于 `Lock` 按钮。
- 成功状态：绿色。
- 无效状态：灰色。
- 危险/反相提示：琥珀色。

### 3.2 字体

- 数字使用等宽字体，保证 dB 和 ms 对齐。
- 标题使用无衬线字体。

### 3.3 反馈

- 分析中：按钮显示 `Analyzing...`。
- 成功：按钮短时显示 `Locked`。
- 无 sidechain：状态区显示 `No Kick Sidechain`。
- 弱信号：状态区显示 `Low signal — play more audio`。

## 4. 交互状态

| 状态 | 触发 | UI 表现 |
|---|---|---|
| Idle | 插件打开 | 主按钮可点击 |
| Analyzing | 点击 Lock | 主按钮禁用，进度动画 |
| Locked | 分析完成 | 显示结果，主按钮恢复 |
| Manual | 用户调整参数 | `Auto` 指示灯熄灭 |
| No Sidechain | 无 sidechain 输入 | 警告提示 |
| Low Signal | 输入过弱 | 提示继续播放 |

## 5. 首次使用引导

建议使用轻量 tooltip 或内置引导：

1. “把 Low-End Lock 插入 Bass 轨。”
2. “把 Kick 轨路由到 sidechain。”
3. “播放同时包含 Kick 和 Bass 的片段。”
4. “点击 Lock。”

## 6. 无障碍与可读性

- 控件支持键盘焦点。
- 文本对比度满足基本可读性。
- 不以颜色作为唯一状态指示，辅以文字。

## 7. 预设

- `Default`：标准低频对齐。
- `Tight Kick`：更适合短促底鼓。
- `Sustained Bass`：更适合长音 Bass。
- `Manual Start`：自动关闭，用户手动调整。

## 8. UX 验收标准

- 新用户可在 60 秒内完成第一次锁定。
- 用户能复述 `Cancelation Saved` 的含义。
- 无需阅读手册即可完成 sidechain 路由和主按钮操作。
