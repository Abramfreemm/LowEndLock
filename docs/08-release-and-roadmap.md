# Low-End Lock — 版本路线与发布计划

## 1. 阶段总览

| 阶段 | 目标 | 主要产出 |
|---|---|---|
| M0 Pre-dev | 冻结产品与技术 | 本文档集 |
| M1 Prototype | 验证算法 | 命令行/参考 DSP |
| M2 MVP | 插件可用 | VST3/AU 内测版 |
| M3 Beta | 真实用户验证 | Beta 版 + 反馈 |
| M4 V1.0 | 首次商业发布 | 正式版 + 官网 |
| M5 Post-launch | 迭代与扩展 | v1.1、新平台 |

## 2. M1 Prototype

### 目标

- 用 Python/NumPy 或 C++ 命令行验证核心算法。
- 证明自动极性与时间对齐有效。

### 完成标准

- 合成测试通过。
- 真实样本主观验证有效。
- 形成算法参数初值。

## 3. M2 MVP

### 功能范围

- VST3/AU。
- 单视图 UI。
- `Lock`、`Cancelation Saved`、A/B。
- 手动 Polarity、Delay、Low Cut、Mix。
- Sidechain。
- 预设保存。

### 完成标准

- 通过 `docs/06-test-plan.md` 发布门槛。

## 4. M3 Beta

### 目标

- 30 名以上用户试用。
- 验证价格、信息架构、算法满意度。

### 收集数据

- 首次成功率。
- 用户是否理解指标。
- 常见 DAW 兼容问题。
- 愿意付费价格区间。

## 5. M4 V1.0

### 发布内容

- 正式安装包。
- 官网落地页。
- 30 秒问题演示视频。
- 使用手册。
- 邮件列表 / 社区渠道。

### 定价假设

- 首发建议：$29–$49 一次性买断。
- 提供 14 天免费试用或限制版。

## 6. M5 Post-launch

候选方向：

1. CLAP / AAX。
2. 多实例联动。
3. 自动分离 Kick/Bass。
4. 实时相位关系可视化。
5. 预设包。
6. 移动/硬件合作。
