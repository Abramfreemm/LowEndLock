# Low-End Lock — 产品愿景与市场判断

## 1. 文档信息

- 文档版本：v1.0
- 状态：Draft for review
- 作者：Product / Technical lead
- 日期：2026-09-19

## 2. 一句话产品定义

Low-End Lock 是一款实时音频插件，自动检测 Kick 与 Bass 之间的低频相位抵消，并一键补偿极性与时间差，帮助制作人找回被吃掉的低频能量。

## 3. 背景

在电子、嘻哈、摇滚、流行等现代制作中，Kick 和 Bass 是最重要、也最容易冲突的两条低频内容。二者同时发声时，如果相位关系不佳，低频会互相抵消，导致：

- 底鼓失去冲击力；
- Bass 变薄；
- 混音在耳机中尚可，但在手机、蓝牙音箱、现场系统中明显塌陷；
- 制作人反复 EQ、压缩、叠加谐波，却无法解决根本问题。

这个痛点在制作人社区已经被充分验证。它不是需要教育的新概念，而是用户已经遇到的问题。

## 4. 市场信号

现有产品已经证明该问题具备商业价值：

- Waves InPhase：全功能相位修正工具。
- Sound Radix Auto-Align / Pi：多轨相位对齐。
- Mastering The Mix FUSER：频率冲突与相位分析。
- AIDE Audio GE-1 Gravity Engine：Bass 工具中内建 kick phase alignment。
- DeepPerfection：专做实时低频相位校正。

这些产品通常功能较深、概念较专业、学习成本较高。市场上仍缺少一个：

- 只针对 Kick/Bass 低频；
- 一键操作；
- 明确显示“找回多少 dB”；
- 价格低、可快速试用的产品。

## 5. 目标用户

### 主要用户

**卧室制作人 / Beatmaker / 电子音乐制作人**

- 使用 Ableton Live、FL Studio、Logic Pro、Studio One。
- 知道 Kick 与 Bass 有冲突，但不熟悉相位理论。
- 想要快速、直观的解决办法。

### 次要用户

**混音师 / 独立工程师**

- 已有专业工具，但希望有一个轻量、快速、结果可视化的低频对齐工具。

### 延伸用户

**直播、播客、短视频音乐制作**

- 不追求深度技术，只希望成品在手机端低频不塌。

## 6. 核心价值

1. **快**：一键学习，几秒完成。
2. **准**：只处理低频，不影响中高频立体声像。
3. **可感知**：用 dB 数字和 A/B 让修复效果可听见、可看见。
4. **低风险**：低 CPU、低延迟、无 AI 黑盒。

## 7. 差异化

| 维度 | 传统工具 | Low-End Lock |
|---|---|---|
| 处理范围 | 全频段 / 多轨 | 只处理 Kick/Bass 低频 |
| 主要操作 | 多参数、多步骤 | 一个 Lock 按钮 |
| 结果反馈 | 相位表、相关系数 | Cancelation Saved dB |
| 学习成本 | 高 | 低 |
| 产品故事 | 专业工具 | 快速修复 |

## 8. 非目标

MVP 阶段明确不做：

- 全频段相位对齐。
- 多麦克风鼓组自动对齐。
- 智能 EQ / 动态 EQ。
- 云端 AI 分析。
- 完整母带链。
- 订阅制后台。

## 9. 成功指标

### 产品可用性

- 新用户在 60 秒内能完成第一次 Kick/Bass 锁定。
- 80% 测试样本中，`Lock` 后低频能量至少恢复到“更优极性 + 时间补偿”的理论上限附近。
- 插件在默认设置下实时 CPU 占用低于目标值。

### 商业验证指标

- Beta 期收集至少 30 份制作人反馈。
- 免费试用到付费转化率达到可验证假设。
- 至少 3 个短视频演示素材，能直接展示问题与修复结果。

## 10. 结论

Low-End Lock 不应做“另一个相位工具”，而应做“低频问题的快速修复器”。产品成功的关键不是算法堆料，而是把复杂相位问题压缩成一个按钮和一个 dB 数字。
