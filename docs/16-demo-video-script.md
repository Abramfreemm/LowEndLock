# Low-End Lock — 演示视频脚本（约 60 秒）

> 目标：让评委在 10 秒内看懂「它解决什么问题」，60 秒内看到「效果多明显」。
> 建议竖屏或横屏均可；音画同步录制，配简洁字幕。

## 结构总览

| 时间 | 内容 |
|---|---|
| 0–8s | 钩子：抛出痛点（低频发虚） |
| 8–35s | 核心演示：反相 → Lock → 数字跳 → 波形对齐 |
| 35–50s | A/B 对比 + 结论 |
| 50–60s | 结尾：一句话定位 + 名称/Logo |

## 分镜脚本

### 0–8s（钩子）

- **画面**：一个 kick + bass 的循环在播放，低频明显「薄、虚、没有冲击力」。
- **字幕/旁白**：「Kick 和 Bass 一叠，低频就发虚？——它们在互相抵消。」
- **画面**：切到插件 UI，橙色 Bass 和青色 Kick 波形**反向错开**。

### 8–20s（建立问题）

- **画面**：Bass 轨上插入 LowEndLock，侧链选 Kick。
- **字幕**：「传统做法是压音量躲开，我们把它们**对齐**。」
- **画面**：手指/鼠标移到 `Lock` 按钮。

### 20–35s（核心演示，最关键）

- **动作**：点击 `Lock`，画面显示 `Analyzing...`（2 秒）。
- **画面**：主指标 **`Cancelation Saved`** 从 0 跳到 **+7.4 dB**（绿色大数字）。
- **画面**：波形里绿色 `Fixed` 轨迹**贴到青色 Kick**，反相消失。
- **字幕**：「找回被抵消的低频：+7.4 dB。」

### 35–50s（A/B + 结论）

- **动作**：点 `B (fix)` / `A (orig)` 来回切。
- **音频**：A = 薄、虚；B = 实、厚、有冲击力。
- **字幕**：「不压音量，不改变 bass 的性格，只对齐低频。」

### 50–60s（结尾）

- **画面**：插件全貌 + 名称/Logo。
- **字幕**：「Low-End Lock —— 一键锁定你的低频。」

## 录制要点

1. 素材：一条 808 kick + 一条同音高 sub bass（都在 50–60Hz 附近），确保低频明显重叠。
2. 为了让数字大：可临时在 kick（或 bass）轨插 Logic 自带 Gain 勾 `Phase Invert`，制造明显反相，`Cancelation Saved` 就能到 +6~+9 dB。
3. 录音里要能清楚听到 A/B 差别：A 低频发虚，B 低频变实变厚。
4. 全程开插件波形，让评委同时「看到」对齐过程。
5. 字幕用一句话短句，别堆术语。
